# Contract: projects-vfs

## Parties
projects  ->  vfs

## What the edge carries
The knowledge-graph-over-flat-storage edge: projects (a graphical file system /
knowledge graph) points into sections of the flat VFS; project artifacts
(source code, built dashboards, metadata blobs) are stored/retrieved through
VFS. Schema/example deferred. **requirements-only** (round-3, 2026-07-18).
